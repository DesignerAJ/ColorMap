## 수정 완료

### 지역·주소 검색 개선 과제
- [X] 수정 반영 / 말씀드렸던 대로 VWorld, mapbox, Google을 순서대로 기다리지 않고 동시에 부른 뒤 결과를 골라 쓰는 방식으로 바꿨습니다. '남대문시장'을 치면 도로명 '남대문시장4길'이 이기던 문제와 속도 문제가 원인이 같아서 함께 해결되었습니다.
순위는 이름이 정확히 일치하는 것만 위로 올리고 나머지는 예전처럼 제공자 순서(행정지명 → Mapbox → Google → 국내 상호명)를 따릅니다. 참고로 지난번에 말씀드린 카카오는 아직 도입하지 않았습니다. 속도 문제가 동시 호출로 해결돼서 급한 이유가 사라졌다고 판단했습니다. 그래도 VWorld에 대한 의존을 줄이는 의미가 있다면 진행해보도록 하겠습니다.

### 검색 결과 키보드 선택 (추가 작업)
- [X] 수정 반영 / 검색 후 키보드의 ↓로 목록에 내려가 ↑↓로 옮기고 엔터 버튼으로 고를 수 있게 했습니다. 사용 중에 편의 상 있으면 좋은 기능 같아서 추가했습니다.
작업 중 한글 IME 관련 버그가 두 개 나왔고 증상이 하나로 보였습니다(첫 ↓가 두번째 줄로 뛰고, 가만히 두면 선택 표시가 저절로 풀리는 버그). 둘 다 막도록 수정하였습니다.

### 영국 행정구역 표시
- [X] 수정 반영 / 확인주신 대로 선이 4개(잉글랜드, 스코틀랜드, 웨일스, 북아일랜드)로만 그어지는 문제가 있었습니다. 원래 우리 데이터에 들어있던 카운티·단일자치체·런던 자치구에서 선을 다시 뽑았습니다.

### 경로선 끝단 수정
- [X] 수정 반영 / 줌값에 따라 '핀과 선 끝의 거리가 일정하지 않은 문제'가 있었고, 잘라내는 계산은 원래부터 화면 픽셀 기준이었는데 미리보기 때 한 번만 계산해서, 그 뒤로 줌을 바꾸면 줌아웃에서는 간격이 벌어지고 줌인에서는 핀에 파고들었습니다. 이제 줌이 바뀔 때마다 다시 자릅니다.

### 지도 디자인 - 위성사진 버그
- [X] 수정 반영 / 사용 중에 위성사진을 고르면 '지명 표시' 체크박스와 구분선이 같이 사라지던 버그를 고쳤습니다. 사진 위에 색을 얹을 이유가 없어 색 칸을 숨긴 것인데, 칸 전체를 숨기는 바람에 안에 같이 들어 있던 체크박스까지 딸려 갔던 것입니다. 위성사진 스타일에서는 색상 지정 칸이 불필요하여 지명 표시 체크 박스를 한 줄로 중앙 정렬하였는데, 개선 필요하다고 생각되시면 알려주시면 감사하겠습니다.

### 검색 시 생성되는 핀의 삭제 버튼
- [X] 수정 반영 / 지난번 제안드렸던 대로 커스텀 핀 오른쪽 위에 X를 넣었습니다. 핀에 마우스를 올렸을 때만 보이게 했는데, 핀이 여러 개일 때 전부 떠 있으면 디자인 상 번잡해보일 수 있다고 판단해서인데 늘 보이는 편이 낫다거나 개선 의견 주시면 바꾸겠습니다.
출발·도착 핀은 지우는 것이 아니라 옮기는 핀이고 경유지는 자기 목록이 있어서, 개별 핀에만 붙였습니다. 녹화·PNG·PSD 결과물에는 찍히지 않는 상황입니다.

### '출발핀, 경유 핀, 도착 핀, 글자색'과 각 색상 선택 원 배치 수정
- [X] 수정 반영 / 출발 핀·경유 핀·도착 핀·글자색을 '지도 디자인'의 색 칸처럼 라벨 옆에 붙는 형태로 한 줄에 놓았습니다. 우려하셨던 폭을 계산해보니 다행히 여유가 있었습니다.
