## 수정 내용 피드백 확인 / 향후 과제 및 개선 방향

### 지역·주소 검색 개선 과제
- [ ] 의견 요청 / 검색 속도 확인 중에 좀 더 우선적으로 잡을 문제가 있었습니다. 
먼저 ‘남대문시장’을 검색하면 ‘남대문시장4길(도로명 주소)’만 나오고 검색하려는 남대문시장이 나오지 않았습니다. 원인은 적어주신 속도 문제와 근원적으로 같다고 합니다. 지금 검색이 제공자를 순서대로 하나씩 부르다가 결과가 하나라도 나오면 거기서 멈추는 구조입니다. 한글 검색 시에 VWorld 행정 지명 (시도→시군구→읍면동) → Mapbox → Google → VWorld 상호명 순서인데, ‘남대문시장’은 행정구역명이 아니라서 1단계가 0건이고 2단계(Mapbox)가 도로명 ‘남대문시장4길’을 반환하고 여기서 ‘결과 있음’으로 판정되어서 원하는 답이 있는 Google까지 못가게 됩니다. 예시로 확인해보았을 때 서울 / 왕복 1번 / 123ms로 비교적 빨랐으나 광장시장 / 왕복 6번 / 510ms, 경복궁 / 6번 / 620ms로 순서대로 기다리는 구조로 인한 느린 속도였습니다.
따라서 순서대로 기다리는 대신 동시에 부르고 결과를 골라서 쓰는 방식으로 수정하려고 합니다. 부분 일치보다 정확히 이름이 일치하는 결과가 위로 올라와서 속도와 정확도가 동시에 해결될 것 같습니다. 수정 방식 한 번 검토 부탁드립니다.
