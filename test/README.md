# 테스트

```bash
node --test test/*.test.js          # 의존성 없음 — 바로 실행된다
npm install && node --test test/dom/*.test.js   # jsdom 필요
```

`npm test` / `npm run test:dom` / `npm run test:all` 도 같은 일을 한다.
푸시하면 `.github/workflows/qa.yml` 이 둘 다 돌린다 (배포는 건드리지 않는다).

## 두 층으로 나눈 이유

사내 npm 레지스트리가 인증서에 막혀 설치가 안 되는 환경이 있다
(`recorder/tools/build-sido-hires.mjs` 주석 참고). 그래서 **설치 없이 돌아가는 층**을
따로 두었다. jsdom 이 필요한 층은 CI 러너에서 돈다.

| 파일 | 무엇을 지키나 | 의존성 |
|---|---|---|
| `geometry.test.js` | 날짜변경선 아크, 거리 잣대 통일, 좌표 입력 파싱 | 없음 |
| `resolve.test.js` | 검색어 해석 — 애매하면 아무것도 안 고른다 | 없음 |
| `data.test.js` | 경계 데이터 무결성 (자기교차·구멍·국경선 정렬·새만금) | 없음 |
| `consistency.test.js` | 파일 사이의 약속 (`?v=` 일치, DOM id 참조) | 없음 |
| `dom/painters.test.js` | 색칠 4모드 배선 | jsdom |
| `dom/search.test.js` | 검색 제공자 체인, 검색창 Enter | jsdom |
| `dom/border.test.js` | 북쪽 국경선 레이어 | jsdom |
| `dom/cascade.test.js` | CSS 캐스케이드 (어느 규칙이 이기는가) | jsdom |

## 각 테스트가 막고 있는 실제 사고

한 번씩 다 났던 것들이다. 주석에 증상을 적어두었으니 실패하면 그걸 먼저 읽으면 된다.

- 서울→LA 경로가 태평양이 아니라 지구 반대로 돌던 것
- 경로선이 경유지에서 967km 어긋나던 것 (거리 재는 잣대가 두 가지였다)
- 시도 폴리곤 자기교차 41곳 → 화면에 얇은 삼각형이 뻗던 것
- `'구'` 한 글자로 종로구가 조용히 칠해지던 것
- 패널 라벨 34개가 통째로 16px 로 그려지던 것 (2.0 규칙이 명시도로 이기고 있었다)
- 드롭다운 화살표가 `background` 축약형에 지워지던 것
- 그리기 모드 버튼의 흰 배경 위 흰 글씨
- 목록에서 방향키로 고른 뒤 Enter 가 안 먹던 것
- `?v=` 가 파일마다 갈려 고쳐도 화면이 안 바뀌던 것
- 국경선 파일 로드 실패 시 국경선이 통째로 사라지던 것 ← 이 테스트를 쓰다 발견했다
- 투명도를 0 으로 내려도 남던 흰색 국경선 (조절 대상을 id 로 적어 스타일마다 빠뜨렸다)
- 한국·북한 경계선만 점선이 실선으로 보이던 것 (둥근 끝이 대시 간격을 먹었다)
- '이동 중 줌아웃 많이'가 '자동'보다 덜 줌아웃되던 것 (단계가 거리와 무관하게 고정이었다)
- '부드럽게 녹화'에서만 줌아웃이 통째로 없던 것 (직선 보간이라 비행 곡선을 안 탔다)
- 디자이너가 꺼둔 경계선을 켜서 해안선까지 흰 선이 그어지던 것
- tolerance 0 으로 두어 함경남도에 긴 다각형이 뻗던 것 (데이터는 멀쩡했다)
- 행정구역을 나라별로 쪼개다 구역이 새거나 정밀도가 되레 떨어지는 것
- 출처 대장과 실제 데이터가 어긋나는 것 (이미지에 따라붙는 표기 의무라 어긋나면 곤란하다)

## 못 잡는 것

jsdom 에는 WebGL 이 없어서 **실제로 그려진 그림은 검사하지 못한다.**
지도 렌더 결과가 걸린 문제 — 위성 스타일 바다가 뿌옇게 나오던 것, 색칠 다각형에
삼각형이 뻗던 것 — 은 브라우저 스크린샷 회귀(Playwright)가 있어야 잡힌다.
`data.test.js` 가 데이터 쪽 원인은 막아주지만 렌더 단계는 여전히 사각지대다.

## recorder.js 함수를 꺼내 쓰는 방식

검증 대상 함수들이 `initRecorder` 클로저 안에 있어 import 할 수 없다.
`helpers/extract.js` 가 소스에서 해당 선언만 떼어내 평가한다.
함수 이름을 바꾸면 "선언을 찾지 못했다"로 확실히 깨진다 — 조용히 통과하지 않는다.
나중에 ES 모듈로 쪼개면 이 헬퍼는 없애고 `import` 로 바꾸면 된다.
